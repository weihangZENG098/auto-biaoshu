# auto-biaoshu

自动化标书编制工作流 — 基于 AI 多 Agent 并行协作，实现政府采购项目投标文件的自动化编制。

## 功能特点

- **多 Agent 并行编写**：技术标、商务标、响应表+承诺函、资信标+报价标四路并行
- **全文直读**：编写师直接读取原始招标文件全文，避免摘要导致的信息丢失
- **三文档强制产出**：资信标 + 报价标 + 技术商务标，缺一不可
- **严格格式规范**：按政府采购标准排版（黑体标题 + 宋体正文 + python-docx生成）

## 使用方式

将 SKILL.md 导入 WorkBuddy/Claude code等的用户级 Skill（~/.workbuddy/skills/），即可在投标任务中自动调用该工作流。

## 适用场景

- 政府采购公开招标项目
- 有明确评分标准和格式要求的项目
- 需要响应星号条款（不可负偏离）的项目
